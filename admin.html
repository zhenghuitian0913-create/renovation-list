打开公开页
怎么编辑（和公开页一样的表格）
  1. 点 加载内容，下方会出现和公开页一样的表格，每个格子直接打字即可（回车就是换行）。
  2. 粘贴的网址（https://...）保存后会自动变成可以点开的链接。
  3. 参考图：点格子里的 ＋ 图片/视频 添加；缩略图上的 换 和 × 分别是替换和删除。
  4. 最左边是行操作：上移 / 下移 / 插入行 / 删除；每节底部还有 新增一行。
  5. 改完点 保存并发布，公开页约 20 秒到 2 分钟自动更新。

首次使用：在上方 Token 框粘贴 GitHub Token（点这里 创建 Token，权限选 Contents: Read and write）。Token 只保存在本机浏览器。
